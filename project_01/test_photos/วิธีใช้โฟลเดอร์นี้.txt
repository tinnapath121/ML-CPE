วางรูปภาพที่อยากทดสอบไว้ในโฟลเดอร์นี้ แล้วรัน:

    python test_svm.py

- ถ้ามีรูปในโฟลเดอร์นี้ -> จะใช้รูปเหล่านี้ทดสอบก่อน (ไม่ใช้ dataset)
- ถ้าโฟลเดอร์นี้ว่าง (ไม่มีไฟล์รูปเลย) -> จะสุ่มภาพจาก test set ของ dataset มาทดสอบแทนเหมือนเดิม

เทคนิค: ถ้าตั้งชื่อไฟล์ขึ้นต้นด้วย with_mask หรือ without_mask (เช่น with_mask_1.jpg)
สคริปต์จะรู้คำตอบที่ถูกต้องจากชื่อไฟล์เอง และขึ้นสีเขียว/แดงบอกถูก-ผิดให้อัตโนมัติ
ถ้าตั้งชื่ออย่างอื่น จะโชว์แค่ผลทำนาย ไม่ฟันธงว่าถูกหรือผิด
