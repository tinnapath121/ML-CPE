# Mask Check-in — ระบบสแกนหน้าเข้างานพร้อมตรวจการสวมหน้ากาก

เว็บแอปสำหรับจุดทางเข้าโรงงาน พนักงานยืนหน้ากล้อง แล้วระบบจะ
1. **ระบุตัวตน** จากใบหน้า ใช้ได้ทั้งตอนสวมหน้ากากและสวมแว่น
2. **ตรวจว่าสวมหน้ากาก** ด้วยโมเดลที่กลุ่มเทรนเอง แยก 3 แบบ: สวมแมส / ไม่สวม / เอามือปิดปาก
3. **ลงเวลาเข้างาน** เมื่อจำหน้าได้และสวมหน้ากาก ถ้าไม่สวมหน้ากากจะไม่ให้เข้า ถ้ายังไม่ได้ลงทะเบียนจะพาไปลงทะเบียน

ระบบใช้ **CNN แบบ Transfer Learning** (SSD MobileNet หาหน้า + ResNet ดึงฟีเจอร์ 128 ค่า) แล้วเทรนส่วนหัวด้วยข้อมูลของกลุ่มเอง

ลงทะเบียนด้วยรูป 2 แบบ คือหน้าตรงไม่สวมหน้ากาก และหน้าตรงสวมหน้ากาก ระบบจะเก็บลายใบหน้าทั้งสองแบบไว้เทียบ
ต่อยอดจาก `ML-CPE/project_01` (SVM ตรวจแมสบน pixel ดิบ ได้ 84.62%)

**เว็บ:** https://tinnapath121.github.io/ML-CPE/ (deploy โฟลเดอร์ `Final-Project/web/` อัตโนมัติด้วย `.github/workflows/pages.yml` ที่ root ของ repo)

## สถาปัตยกรรม

```
กล้องมือถือ
  → เติมขอบภาพ 20% → SSD MobileNet (ตรวจจับใบหน้า, pretrained)
  → Face landmarks 68 จุด → จัดหน้าให้ตรง → ลายใบหน้า 128 ค่า (face descriptor, pretrained)
      ├─→ [ML ของกลุ่ม] MLP ตรวจแมส: with_mask / without_mask / hand_cover
      └─→ [ML ของกลุ่ม] 1-Nearest Neighbor เทียบลายใบหน้าผู้ลงทะเบียน + เกณฑ์ระยะ + margin test (กันจำสลับคน)
  → โหวต 6 เฟรมให้ผลนิ่ง → ตัดสิน: ลงเวลา / ไม่ให้เข้า (ไม่สวมแมส) / ไปลงทะเบียน
```

ภาพจากกล้องประมวลผลในเบราว์เซอร์ ส่งออกไปแค่ลายใบหน้า 128 ค่า และรูปหน้าย่อ 96×96 ตอนลงเวลา (เป็นหลักฐานในรายงาน) ส่วนรายชื่อ ลายใบหน้า และประวัติเก็บในฐานข้อมูลกลาง Supabase เพื่อให้ทุกเครื่องเห็นข้อมูลเดียวกัน — ฐานข้อมูลเทียบลายใบหน้าเอง (pgvector) เบราว์เซอร์ได้กลับมาแค่ชื่อ/ระยะ (ดู `supabase/README.md`)

## Dataset

| ชุด | แหล่ง | ใช้ทำอะไร |
|---|---|---|
| ds1 | [chandrikadeb7/Face-Mask-Detection](https://github.com/chandrikadeb7/Face-Mask-Detection) (ชุดเดียวกับ project_01) | เทรน + 5-fold CV |
| ds2 | [prajnasb/observations](https://github.com/prajnasb/observations) (แมสสังเคราะห์ มีคู่รูปคนเดียวกัน) | ทดสอบข้าม dataset + คาลิเบรตเกณฑ์จดจำใบหน้า |
| real | รูปเซลฟีของผู้พัฒนา + รูปทดสอบจาก project_01 | ทดสอบกับรูปจากกล้องมือถือจริง |

| synth | สร้างเอง: วาดมือสีผิวทับปาก 545 รูป | สอนคลาส "มือปิดปาก" |
| phone | เฟรมจากกล้องมือถือ (แท็บ "เก็บข้อมูล") | ทดสอบมือจริง + เทรนเสริม |

ตัดรูปซ้ำด้วย MD5 ก่อนใช้

## ผลลัพธ์หลัก

- ตรวจแมส (MLP, 5-fold CV): **95.5%** · ทดสอบข้าม dataset 87.8% · รูปจริง 4/4
- มือปิดปาก → ทายว่าใส่แมส: 86% → **7%** (ทดสอบกับมือจริงที่ไม่เคยเห็น)
- จำหน้า: เกณฑ์ 0.55 (คาลิเบรตจาก 154 คู่) · FAR 0.7% · FRR 26.6%
- กันจำสลับคน: คะแนนแต่ละคน = เฉลี่ยระยะ template ใกล้สุด 2 อัน · เกณฑ์หน้าใส่แมส 0.38 / หน้าเปล่า 0.50 · ต้องใกล้กว่าคนอันดับ 2 อย่างน้อย 0.10 · ต้องได้คนเดียวกันติดกัน 6 เฟรม (~1.5 วินาที) ชื่อถึงจะขึ้นจอ · กันลงทะเบียนซ้ำใช้เกณฑ์ 0.40 ครบ 3 เฟรม
- ตรวจแมสเข้ม: เฉลี่ย 6 เฟรม ≥ 0.75 · ทุกเฟรม ≥ 0.50 · ความน่าจะเป็นมือปิดปากทุกเฟรม < 0.25 (ปรับได้ใน `web/model/config.json`)
- รายละเอียด: `ml/results/metrics.md`

## ข้อมูลส่วนบุคคล (PDPA)

- ข้อมูลชีวมิติใบหน้าเป็น **ข้อมูลส่วนบุคคลอ่อนไหว (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล ม.26)** ต้องได้รับความยินยอมโดยชัดแจ้ง → มีช่องให้ติ๊กยินยอมก่อนลงทะเบียน
- ลงทะเบียนเก็บเฉพาะ**ลายใบหน้า** (ตัวเลข 128 ค่า) ไม่เก็บรูปลงทะเบียน · ตอนสแกนเข้างานเก็บ**รูปหน้าย่อ 96×96** เป็นหลักฐาน ซึ่งระบุไว้ในข้อความยินยอมแล้ว · ทั้งหมดอยู่ใน Supabase (สิงคโปร์) ที่ไม่เปิดตารางผ่าน API · ลบได้จากแท็บ "รายชื่อผู้ลงทะเบียน" ด้วย PIN ผู้ดูแล
- การส่งข้อมูลไปเก็บนอกประเทศต้องพิจารณา PDPA ม.28 (ประเทศปลายทางต้องมีมาตรฐานคุ้มครองเพียงพอ) — ระบบจริงควรใช้เซิร์ฟเวอร์ในประเทศหรือของหน่วยงาน
- ถ้าใช้จริงในโรงงาน ต้องย้ายฐานข้อมูลไปเซิร์ฟเวอร์ของหน่วยงานที่เข้ารหัส ควบคุมสิทธิ์ มีบันทึกการเข้าถึง และกำหนดระยะเวลาเก็บ

## ข้อจำกัด

- เกณฑ์จดจำใบหน้าคาลิเบรตจากแมสสังเคราะห์ (ds2) จึงต้องทดสอบกับคนจริงเพิ่ม
- ต้องมีอินเทอร์เน็ตตอนสแกน/ลงทะเบียน · publishable key อยู่ในหน้าเว็บ (ออกแบบให้ทำได้) แต่ยังไม่มีการยืนยันตัวตนอุปกรณ์/จำกัดอัตราการเรียก
- ไม่มีระบบกันการปลอมหน้า (liveness detection) เช่น ใช้รูปถ่ายมาสแกน
